# Storefront sourcing pass — 2026-09-28

330 storefronts checked, **245 confirmed** by the vendor's chat signature in the raw served HTML
(curl, desktop UA; a WebFetch/markdown fetch strips async loaders). **144 of them were added to
`server/candidates.json`** (merged 2026-10-06; 20 more had meanwhile been added by the nightly sourcing), the seed list `server/source-merchants.mjs` verifies nightly in a real
browser (vendor host loads AND a launcher/composer mounts) before anything reaches `vendors.js`.
A signature proves the loader, not a drivable AI chat: nothing here skips that verification.

Added per vendor: Gorgias 41, Zendesk 30, DigitalGenius 17, Intercom 14, Ada 10, Kodif 10,
Yuma 7, Envive 5, Siena 5, Klaviyo 3, Sierra 1, Decagon 1.

Held back:
- **80 confirmed pages that also run another chat vendor** (table below). The benchmark only
  admits a store whose driven widget is attributable to one vendor; these need a rendered probe
  to see which widget actually answers. Most Yuma hits run behind Gorgias.
- Already known hosts (vendors.js or candidates.json) and sweetgreen.com (restaurant).

Caveats per vendor:
- **Gorgias** — only the chat loader is known; whether a store runs AI Agent V3 needs the Cortex
  check (AGENTS.md §5). gen.js drops `v3:false` stores only, so unknown is admitted.
- **Zendesk** — each passed the check that its `ekr.zdassets.com/compose/<key>` config returns the
  messaging product, not legacy chat or a form; whether an AI agent answers is not verified.
- **Klaviyo** — `k-hub` only means Customer Hub is installed. The added stores also pass Klaviyo's
  public hub settings (`fast.a.klaviyo.com/atlas/api/public/settings/<company_id>`,
  `ai_agent_enabled=true`, web chat visible). Only ~6% of hub stores pass; Respire and BaubleBar,
  already registered, do not — worth re-checking why they are in the rotation.
- **Decagon / Sierra** — enterprise customers mostly load the widget from JavaScript bundles or on
  help subdomains, so an HTML-only check structurally undercounts them. Decagon's per-customer
  loader `decagon.ai/loaders/<name>.js` exists for lululemon, Seed, Michaels, Zola, Nurx and FINN,
  none confirmable on the served page (403 or JS-only). Sierra ships in Thrive Market's JS bundle
  (published case study) but not its HTML. These need a rendered probe from the capture box.

Sources: BuiltWith's free top-50 technology lists (`trends.builtwith.com/websitelist/<Tech>`) for
Yuma-AI, Kodif, Siena-AI, Sierra, Decagon, DigitalGenius, Ada-Support, Envive-AI and
Intercom-for-Shopify gave the most; plus ~3,000 storefronts from other Shopify-app lists, reviewer
names on the Fin Shopify app, and brand brainstorming. PublicWWW's search sits behind a browser
check and was not used.
