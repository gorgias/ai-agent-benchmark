MCP server

Ask your AI assistant about the benchmark

A public MCP server with the same rankings and store scores as this site. No sign-up, refreshed after every daily run, and you can ask for a new store to be evaluated.

https://evals.gorgias.com/mcp

Streamable HTTP · no authentication · no conversation transcripts

Connect

Claude

Open Settings → Connectors, choose Add custom connector, name it “Gorgias benchmark” and paste the URL. Leave authentication empty. On Team and Enterprise plans, an owner may need to add it first.

Claude Code

Terminal
claude mcp add --transport http gorgias-benchmark https://evals.gorgias.com/mcp

Cursor, Windsurf and other clients

MCP config
{
  "mcpServers": {
    "gorgias-benchmark": { "url": "https://evals.gorgias.com/mcp" }
  }
}

VS Code uses a servers block with "type": "http" and the same URL.

Tools

  • get_rankings: the leaderboard for overall, shopping (pre-sale) or support (post-sale), with composite, automation rate, answer quality, latency and conversations per vendor.“Who leads the support lane?”
  • get_vendor: one vendor's scorecard in every lane.“How does Sierra do on shopping?”
  • compare_vendors: two to six vendors side by side.“Compare Gorgias, Sierra and Ada.”
  • get_store: one storefront's scores in each lane, with its vendor's composite for context.“How does Alo Yoga's AI agent score?”
  • request_store: ask for a storefront to be crawled and evaluated. Its AI chat must come from a supported vendor; the next daily run verifies it and first scores follow within a day or two.“Add hushblankets.com to the benchmark.”
  • get_methodology: lanes, composite weights, speed score and ranking rules.“How is the composite calculated?”

What's in it

Vendor rankings and per-store scores from a trailing 90-day window of live-storefront conversations. Conversation transcripts are not included. The same data is a plain JSON file at evals.gorgias.com/board.json. Published by Gorgias; cite evals.gorgias.com when you quote it.
