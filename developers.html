For AI assistants

Benchmark MCP server

Ask Claude, Cursor or any MCP client about the benchmark. The server returns the same vendor rankings as this site: read-only, no sign-up, refreshed after every daily run.

https://evals.gorgias.com/mcp

Streamable HTTP · no authentication · vendor-level data only

Connect

Add the URL above as a remote MCP server. Nothing to install and no key to create.

Claude

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it “Gorgias benchmark” and paste the URL. Leave authentication empty.

On Team and Enterprise plans, an owner may need to add the connector first.

Claude Code

Terminal
claude mcp add --transport http gorgias-benchmark https://evals.gorgias.com/mcp

Cursor, Windsurf and other clients

MCP config
{
  "mcpServers": {
    "gorgias-benchmark": {
      "url": "https://evals.gorgias.com/mcp"
    }
  }
}

VS Code uses a servers block with "type": "http" and the same URL.

Tools

Four read-only tools. Your assistant picks the right one from the question.

ToolReturns
get_rankingsThe leaderboard for one lane: overall, shopping (pre-sale) or support (post-sale). Composite, automation rate, answer quality, mean and p75 latency, conversations and a 95% interval per vendor.“Who leads the support lane?”
get_vendorOne vendor's scorecard in every lane, with its rank out of the ranked field.“How does Sierra do on shopping?”
compare_vendorsTwo to six vendors side by side, per lane, with the lane leader for reference.“Compare Gorgias, Sierra and Ada.”
get_methodologyHow the benchmark measures and ranks: lanes, composite weights, speed score, the 90-day window and the rankability floor.“How is the composite calculated?”

What's in it

The figures the public pages show, from a trailing 90-day window of live-storefront conversations. The server reads the same file the site is built from, so the two never disagree.

Included

  • Vendor ranks and scores, overall and per lane
  • Automation rate, blind LLM-judged answer quality, latency
  • Conversation counts and 95% intervals
  • Composite weights and scoring rules

Not included

  • Store-level results
  • Conversation transcripts

Figures are published by Gorgias. Cite evals.gorgias.com when you quote them.

Without MCP

The same data is a plain JSON file at evals.gorgias.com/board.json. To test the server from a terminal:

Terminal
curl -s https://evals.gorgias.com/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_rankings","arguments":{"lane":"support"}}}'
